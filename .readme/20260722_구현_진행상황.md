## 한 줄 요약

EMEditor 같은 대용량(10GB+) CSV/TSV 뷰어 MVP를 Rust + egui로 구현 완료. 12개 태스크 + 최종 리뷰 + UI 수정까지 끝. 빌드 경고 0, 테스트 38/38. GUI 기본 동작 확인됨. **아직 master 미머지 / PR 미생성.**

## 아키텍처 (4 모듈, 완성)

- `src/source.rs` — memmap2 파일 매핑, byte 슬라이스. 빈 파일은 Option<Mmap>=None (Windows anon-map 런타임 실패 회피)
- `src/index.rs` — LineIndex (줄 offset Vec<u64> + Phase/상태, Arc 공유, 스레드 안전)
- `src/parse.rs` — 인코딩 감지(BOM→UTF-8→CP949), 디코딩(encoding_rs), 구분자 감지, csv-core 필드 분리, 헤더 감지
- `src/indexer.rs` — scan_offsets(테스트 oracle) + index_range(청크 처리) + spawn_indexer(백그라운드 워커, 8MB 청크, pause/resume)
- `src/app.rs` — egui UI: 툴바(파일열기/구분자/인코딩/헤더/파일명), 가상스크롤 테이블, 상태바(진행률/중단·이어서/행수)
- `src/main.rs` — eframe 진입점 + install_korean_font(맑은 고딕) + 텍스트 크기 설정

## 동작 방식 (핵심)

- 2단계 로딩: open_path에서 앞부분 64KB 프라이밍(즉시 감지+표시) → spawn_indexer가 백그라운드로 전체 개행 offset 인덱싱
- 가상 스크롤: body.rows(ROW_HEIGHT, data_rows) — 보이는 행만 파싱. data_rows는 line_count에서 매 프레임 계산되어 인덱싱 진행에 따라 성장 ("읽은 데까지만 스크롤")
- 중단/이어서 = 상태바 버튼 토글. resume는 bytes_done부터 새 워커 spawn
- 감지 3종(인코딩/구분자/헤더) 모두 툴바 드롭다운/체크박스로 수동 덮어쓰기 가능

## 최근 UI 수정 (사용자 실사용 피드백 반영)

1. **한글 두부(□) 해결**: main.rs에서 Windows malgun.ttf 런타임 로드 → egui 등록
2. **폰트 번짐 완화**: body/button 15px, ROW_HEIGHT 20→22px (세로 글자 겹침 방지)
3. **창 높이 안 채우던 버그**: TableBuilder max_scroll_height 기본 800px 제한이 ~35행에서 멈추게 함 → available_height()로 변경 + auto_shrink([false,false]) + 컬럼 auto()→initial(고정폭)+resizable
4. **셀 truncate**: 긴 값이 wrap해서 행 높이 부풀던 것 방지 (라인번호/헤더/데이터 셀 모두 Label::truncate())
5. **Ctrl+휠 줌**: zoom_factor 0.5~4.0배 (사용자 확인 완료 "잘 된다")
6. dead_code 경고 정리(offset/scan_offsets에 #[allow] + 사유 주석)
7. 테스트 격리 flaky 수정: 임시 파일명을 내용길이→프로세스ID+원자카운터로 (병렬 경합 제거)

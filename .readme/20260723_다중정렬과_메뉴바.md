# 다중 컬럼 정렬 + 메뉴바 / 행·열 번호 설정

- 날짜: 2026-07-23
- 목적: 다중 컬럼 정렬, 메뉴바(파일/도구), 행/열 번호 시작값 설정 정리

## 한 줄 요약

여러 컬럼을 1차/2차/… 우선순위로 정렬(모달 다이얼로그로 기준 편집)하는 다중
컬럼 정렬을 추가하고, 툴바가 넘치는 것을 대비해 **메뉴바(파일/도구)**를 도입,
**행/열 번호 시작값(0/1)** 설정 다이얼로그를 붙였다. 기존 고속 정렬 인프라를
그대로 재사용. master 로컬 머지 예정, 테스트 76/76, 빌드 경고 0.

## 1. 다중 컬럼 정렬

### 기능
툴바/도구 메뉴의 "다중 정렬…" → 모달 창에서 정렬 기준 목록(위=1차) 편집:
각 행 = [순위][컬럼][문자/숫자][오름/내림][삭제]. "+기준 추가"(최대 4개), "정렬".
예: 1순위 도시 문자↑, 2순위 나이 숫자↓ → 도시로 묶고 그 안에서 나이 내림차순.

### 설계 (docs/superpowers/specs/2026-07-23-multi-column-sort-design.md)
- **고정 개수 키 배열**: 최대 4기준. 키 = `([u64; 4], u32 row)`. 앞 기준부터 정수
  비교(Ord 자동), 동률이면 다음 키, 최종 동률이면 원본 행번호로 안정화.
- **방향을 키에 인코딩**: 내림(Desc) 기준은 키를 비트 반전(`!key`)해 배열에 담는다.
  이러면 오름/내림 혼합도 `[u64;4]` 단일 정수 비교로 전체 순서가 나온다(비교
  클로저에 방향 분기 불필요).
  - 숫자 비수치(NUM_INVALID=u64::MAX)는 Desc에서도 반전하지 않아 항상 맨 뒤 유지.
    유효 Desc 키의 최댓값은 u64::MAX에 도달 못 하므로 비수치가 뒤에 남는다.
- **8바이트 prefix 비교**: 다중은 tie-break 원본 재접근 없이 앞 8B u64 키로만
  비교(단순화). 8B 넘어 같으면 다음 정렬 기준으로 넘어감.
- 기존 인프라 재사용: 락 없는 snapshot, par_chunks_mut 순차 순회, 백그라운드
  스레드(spawn_multi_sort) + 진행률 바.

### 핵심 함수(src/sort.rs)
- `SortSpec { col, kind, dir }`, `MAX_KEYS = 4`.
- `col_key(field, spec) -> u64`: 컬럼 값 → 방향 반영 u64 키(비수치 예외).
- `multi_key_for_row(...) -> [u64; 4]`: 한 행에서 specs 순서대로 키 배열.
- `extract_and_multi_sort(...)`: 다중 버전(단일 extract_and_sort와 대칭).
- `spawn_multi_sort(...) -> SortJob`: 백그라운드 래퍼. SortJob.specs 필드 추가.

### UI(src/app.rs)
- Document에 `show_sort_dialog`, `sort_specs: Vec<SortSpec>`. SortState에
  `spec_count`(상태바 "N개 기준 정렬됨" 표시).
- `render_sort_dialog`: egui::Window 모달. 컬럼 ComboBox(헤더 이름 라벨),
  문자/숫자, 오름/내림, 삭제/추가. 컬럼 라벨 번호는 col_base 반영.

## 2. 메뉴바 (파일 / 도구)

툴바가 한 줄에 다 안 들어가는 것을 대비해 최상단 메뉴바 도입:
- **파일** → 열기… (기존 툴바 "파일 열기" 버튼을 메뉴로 이동)
- **도구** → 다중 정렬… / 행·열 번호… (파일 열림 + 조건 충족 시 활성)
- 기존 툴바(구분자/인코딩/헤더/단일 정렬 버튼)는 그대로 유지 — 자주 쓰는 것은
  한 클릭 접근 유지.

## 3. 행/열 번호 시작값

- App 레벨 설정(파일 바꿔도 유지): `row_base`, `col_base`(각 0 또는 1). **기본 0**.
- 도구 → 행·열 번호… → 다이얼로그에서 행 0/1, 열 0/1 각각 선택.
- 렌더 반영: 라인번호 = `표시순번 + row_base`, 컬럼 헤더 번호 = `c + col_base`.
  표 모드/텍스트 모드/다중 정렬 다이얼로그 컬럼 라벨 모두 적용.
